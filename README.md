# KeePassXC to Token2 PIN+ R3.3 TOTP Sync

Безопасная автономная кроссплатформенная утилита для синхронизации TOTP-профилей из зашифрованной базы данных KeePassXC (`.kdbx`) на аппаратные USB-токены безопасности **Token2 PIN+ R3.3** (до 300 аппаратных слотов).

---

## ⚡ Главное в версии 0.2.0 (Zero-External-CLI)

- **Полная автономность (Zero-External-CLI)**: Больше **не требуется** устанавливать сторонние утилиты `keepassxc-cli` или `token2-otp-cli`. Всё встроено:
  - Прямое чтение базы `.kdbx` (KDBX 3.1/4.0/4.1, Argon2id, AES, ChaCha20, Twofish) в оперативной памяти через `pykeepass`.
  - Встроенный драйвер протокола Token2 USB-HID (NIST P-256 ECDH + AES-256-CBC) через `hidapi`.
  - Автоматический fallback на CLI только при необходимости (например, YubiKey Challenge-Response слоты).
- **Интерактивный TUI и Мастер первого запуска (Onboarding Wizard)**:
  - При первом запуске запускается пошаговый мастер настройки прямо в терминале.
  - Нативный графический диалог выбора файлов ОС (кнопка «Обзор» открывает нативный диалог проводника в Windows / zenity / kdialog в Linux / Tkinter) с переходом на консольный ввод в headless/SSH окружениях.
  - Настройки (пути, ключевые файлы, исключаемые группы) редактируются прямо через TUI меню, без необходимости вручную править конфиги.
  - Безопасный режим **Dry Run (Тестовый прогон)** для предварительного просмотра изменений без физической записи на устройство.
- **Портативные автономные бинарники**:
  - Готовые исполняемые файлы без необходимости устанавливать Python: `t2-kpxc-sync.exe` (Windows) и `t2-kpxc-sync` (Linux).

## 🔒 Безопасность и аппаратная защита

- **Zero-Disk-Footprint & Read-Only**: База KeePassXC открывается **строго в режиме чтения**. Никаких незашифрованных XML/дампов или временных файлов на диске не создается.
- **Детекция ротации ключей без записи в KDBX**: Для определения измененных секретов утилита генерирует в оперативной памяти TOTP-код для текущего момента времени $T$ и сравнивает его с кодом, возвращаемым аппаратным токеном.
- **Очистка памяти**: Пароли базы, PIN-код токена и сырые секреты хранятся в изменяемых буферах `bytearray` и принудительно зануляются (`scrub_bytes`) в блоках `finally`. Секреты никогда не передаются через аргументы процессов (`sys.argv`).
- **Защита аппаратного счетчика PIN**: При ошибке ввода PIN-кода утилита немедленно прерывает выполнение, предотвращая аппаратную блокировку токена.
- **Защита от смены типа устройства**: Команды изменения типа устройства (`CMD_SET_DEVICE_TYPE`) заблокированы на уровне протокола для исключения окирпичивания.

## 🚀 Как запустить и пользоваться

### Вариант 1. Автономный исполняемый файл (Без установки Python) — Рекомендуется

1. Перейдите в [GitHub Releases v0.2.0](https://github.com/viz6411/KeePass-to-Token2-OTP-sync/releases/tag/v0.2.0) и скачайте архив под вашу систему:
   - **Windows**: `t2-kpxc-sync-v0.2.0-windows-x64.zip` (содержит `t2-kpxc-sync.exe` и лаунчер `Sync-Token2.bat`) или напрямую исполняемый файл `t2-kpxc-sync.exe`.
   - **Linux**: `t2-kpxc-sync-v0.2.0-linux-x64.tar.gz` (содержит бинарник `t2-kpxc-sync` и лаунчер `Sync-Token2.sh`).
2. Распакуйте архив и запустите лаунчер в 1 клик:
   - **Windows**: Двойной клик по `Sync-Token2.bat` (или запуск `t2-kpxc-sync.exe`).
   - **Linux**: Запуск `./Sync-Token2.sh` или `./t2-kpxc-sync`.
3. При первом запуске откроется **Мастер первого запуска (Onboarding Wizard)**:
   - Утилита предложит выбрать путь к вашей базе `.kdbx` через нативное окно выбора файла проводника.
   - Опционально укажите путь к ключевому файлу (`.key`/`.keyx`).
   - Настройки автоматически сохранятся в локальный `config.toml`.

> **Примечание для Linux**: Для доступа к USB HID токену без прав root настройте правило udev:
> ```bash
> echo 'SUBSYSTEM=="usb", ATTR{idVendor}=="349e", MODE="0660", GROUP="plugdev", TAG+="uaccess"' | sudo tee /etc/udev/rules.d/70-token2.rules
> sudo udevadm control --reload && sudo udevadm trigger
> ```

---

### Вариант 2. Запуск через Python (3.11+)

Если вы предпочитаете запускать утилиту из исходного кода или через pip:

```bash
git clone https://github.com/viz6411/KeePass-to-Token2-OTP-sync.git
cd KeePass-to-Token2-OTP-sync
pip install .
```

После установки доступна команда:
```bash
t2-kpxc-sync
```

Либо запустите умный лаунчер:
- Windows: `Sync-Token2.bat`
- Linux: `./Sync-Token2.sh`
- macOS: `./Sync-Token2.command`

## 🖥️ Интерактивное TUI-меню

После запуска и ввода паролей отображается главное интерактивное меню:

```text
[1] Запуск синхронизации
[2] Тестовый прогон (Dry Run)
[3] Настройки (база, keyfile, группы)
[4] Выход
```

### Режимы синхронизации:
- **[1] Add Only** — записать на токен только новые TOTP-профили, не трогая существующие.
- **[2] Add & Update** — добавить новые и обновить измененные (ротированные) профили.
- **[3] Full Sync** — полная синхронизация (добавление новых, обновление измененных и удаление устаревших профилей с запросом подтверждения `[y/N]`).
- **[4] Cancel** — отмена и выход без записи на токен.
