# KeePass to Token2 PIN+ OTP Sync

Безопасная кроссплатформенная утилита синхронизации TOTP-профилей из KeePassXC (`.kdbx`) на аппаратные токены безопасности **Token2 PIN+ R3.3** (до 300 профилей).

## Особенности
- **Zero-Disk-Footprint & Read-Only**: Никаких незашифрованных дампов на диске. База KeePassXC открывается строго в режиме чтения через потоковый pipe в RAM.
- **Детекция ротации ключей**: Сверка актуальности TOTP без модификации базы KeePassXC (сопоставление сгенерированных кодов в реальном времени).
- **Безопасность памяти**: Все секреты и пароли хранятся в изменяемых буферах памяти и гарантированно затираются нулями по завершении сессии.
- **Интерактивные режимы сверки**:
  1. *Add Only* — добавление только новых профилей.
  2. *Add & Update* — добавление новых и обновление измененных.
  3. *Full Sync* — полная синхронизация с удалением устаревших профилей (с подтверждением).
- **Запуск в один клик**: Готовые лаунчеры для Windows (`.bat`), Linux (`.sh`/desktop) и macOS (`.command`).
