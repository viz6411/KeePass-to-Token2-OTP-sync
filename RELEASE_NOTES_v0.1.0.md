# KeePassXC to Token2 PIN+ R3.3 Sync — Release v0.1.0 (MVP)

Первый официальный релиз утилиты безопасной синхронизации TOTP-профилей между KeePassXC и аппаратными токенами Token2 PIN+ R3.3.

## Что включено в релиз
- **Zero-Disk-Footprint & Read-Only**: Потоковый экспорт KDBX через pipe `keepassxc-cli` напрямую в RAM. База защищена от изменений, промежуточные дампы на диск не записываются.
- **Сверка TOTP без модификации базы**: Определение ротации ключей по несовпадению текущего RFC 6238 TOTP-кода в реальном времени.
- **Адаптер Token2 PIN+ R3.3**: Поддержка токенов до 300 слотов, чтение/запись профилей, немедленная блокировка при неверном PIN для защиты аппаратного счетчика.
- **Безопасность памяти**: Все пароли и секреты хранятся в `bytearray` и гарантированно зануляются в блоках `finally`.
- **Интерактивный Rich TUI**: Наглядная сводка и 3 режима синхронизации (`Add Only`, `Add & Update`, `Full Sync` с подтверждением удаления).
- **Скрипты запуска в один клик**: `Sync-Token2.bat` (Windows), `Sync-Token2.sh` (Linux), `Sync-Token2.command` (macOS).

## Прикрепленные файлы релиза
1. `t2-kpxc-sync-v0.1.0-portable.zip` — Готовый портативный архив со всеми скриптами запуска в 1 клик, исходниками и примером конфигурации.
2. `t2_kpxc_sync-0.1.0-py3-none-any.whl` — Стандартный Python Wheel пакет (`pip install t2_kpxc_sync-0.1.0-py3-none-any.whl`).
3. `t2_kpxc_sync-0.1.0.tar.gz` — Исходный архив для сборки.

Подробная инструкция по установке и настройке доступна в [README.md](https://github.com/viz6411/KeePass-to-Token2-OTP-sync#readme).
