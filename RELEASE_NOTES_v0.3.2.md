# Release Notes — v0.3.2 Hotfix

### 🚀 Обзор релиза v0.3.2
Релиз **v0.3.2** содержит критический хотфикс для стабилизации обнаружения и подключения к аппаратным ключам **Token2 PIN+ Series (R3.3)** по прямому протоколу USB-HID, а также добавляет отображение динамического статуса подключения токена в TUI.

---

### 🛠️ Что исправлено и улучшено:

1. **Последовательный опрос интерфейсов составного USB-HID устройства (`HIDTransport.open`)**:
   - Токены Token2 PIN+ представляют собой составные USB-устройства, экспонирующие несколько интерфейсов HID (например, FIDO2 `usage_page 0xF1D0` и вендорный TOTP `usage_page 0xFF00`).
   - В ОС Windows интерфейс FIDO2 эксклюзивно блокируется системной службой Windows Hello / WebAuthn, из-за чего попытка открыть первый попавшийся путь устройства вызывала системную ошибку доступа (`open failed: access denied`).
   - Теперь драйвер последовательно проверяет все доступные пути и интерфейсы с VID `0x349E` или дескриптором `TOKEN2`, перехватывает ошибки заблокированных интерфейсов и гарантированно подключается к свободному интерфейсу TOTP.

2. **Устранение ложной ошибки отсутствия `token2-otp-cli` (`Token2Adapter.open`)**:
   - Ранее в автоматическом режиме (`backend="auto"`) при сбое прямого USB-HID драйвер безусловно пытался инициализировать `Token2CLIAdapter`, порождая сбивающую с толку ошибку `Token2 Error: Token2 CLI binary not found: 'token2-otp-cli'`, даже когда пользователь не устанавливал и не настраивал утилиту Token2 CLI.
   - Теперь fallback на CLI происходит **только** в том случае, если бинарник `token2-otp-cli` действительно установлен в системе (`shutil.which`). При его отсутствии отображается корректная диагностическая ошибка прямого USB-драйвера.

3. **Динамический статус подключения аппаратного токена в TUI (`tui.py`)**:
   - В верхнюю панель главного меню TUI добавлено отображение состояния аппаратного токена в реальном времени:
     `Hardware: Token2 PIN+ (Connected)` (зеленым цветом) или `(Not detected)` (красным цветом).
   - Заголовок меню теперь отображает динамическую версию `v0.3.2 • Standalone` вместо жестко закодированной строки.

4. **Конфигурация бэкенда токена (`backend = "auto"` в `[token2]`)**:
   - В `Token2Config`, `config.toml` и `config.example.toml` добавлен параметр `backend`:
     - `"auto"` — приоритетный прямой USB-HID, с резервным переключением на CLI при его установке;
     - `"direct"` — строго прямое бесклиентское USB-HID взаимодействие;
     - `"cli"` — принудительное использование внешней утилиты.
