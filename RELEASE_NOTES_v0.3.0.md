# KeePassXC to Token2 PIN+ R3.3 Sync — Release v0.3.0

Релиз v0.3.0 добавляет поддержку выбора формата сохранения TOTP записей на аппаратном ключе Token2 PIN+ R3.3 (обычный формат или формат, требующий физического нажатия кнопки на токене для отображения одноразового кода).

## Ключевые нововведения v0.3.0

### 1. Выбор формата TOTP на финальном шаге перед записью
- При выполнении любой операции записи (`Add Only`, `Add & Update`, `Full Sync`) после утверждения плана синхронизации TUI запрашивает желаемый формат записи:
  - **[1] Обычный формат (Standard)** — код генерируется и возвращается автоматически при запросе с токена (по умолчанию).
  - **[2] Требовать нажатия кнопки (Require a button press to show the code)** — на токене активируется защита касанием (`btn_flag = 0x01`): для генерации и отображения 6/8-значного кода требуется физическое нажатие/касание кнопки на токене.

### 2. Настройка формата TOTP по умолчанию в TUI и конфигурации
- **Меню настроек TUI**:
  - Добавлен пункт `[6] Изменить формат TOTP по умолчанию`, позволяющий переключать стандартный формат для последующих запусков.
  - В информационной панели сводки настроек выводится текущий выбранный формат.
- **Файл конфигурации (`config.toml`)**:
  - Параметр `[token2] button_required = true/false` сохраняет настройку между запусками.

### 3. Пакетный режим CLI
- Добавлен флаг командной строки `--button-required` для утилиты `t2-kpxc-sync`, позволяющий активировать требование нажатия кнопки в неинтерактивных и CI/скриптовых сценариях.

### 4. Аппаратный протокол и модель данных
- На уровне USB-HID протокола Token2 передается флаг `btn_flag` (байт 5 расшифрованного пакета `CMD_WRITE_SEED`).
- Для fallback-режима через `token2-otp-cli` передается аргумент `--button-required`.
- Модель `Token2Profile` сохраняет флаг `btn_flag`, полученный при считывании списка профилей с ключа.

### 5. Всестороннее тестирование
- Пирамида тестов расширена до **403 автоматических тестов** (100% passed).
- Покрыты: интерактивный выбор формата, переключение в меню настроек, сброс к умолчаниям, валидация флагов CLI и сквозная передача байта `btn_flag` в APDU.

## Содержимое релиза
1. `t2-kpxc-sync-v0.3.0-linux-x64.tar.gz` — Портативный архив для 64-битного Linux со скомпилированным бинарником, лаунчером `Sync-Token2.sh`, документацией и архитектурной картой.
2. `t2-kpxc-sync-v0.3.0-windows-x64.zip` — Портативный архив для 64-битного Windows со скомпилированным `.exe`, батником `Sync-Token2.bat` и документацией.
3. Автономные бинарные файлы `t2-kpxc-sync` (Linux) и `t2-kpxc-sync.exe` (Windows).
4. `SHA256SUMS.txt` — Контрольные суммы SHA-256 файлов релиза.
