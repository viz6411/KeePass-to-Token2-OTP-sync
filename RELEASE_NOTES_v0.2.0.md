# KeePassXC to Token2 PIN+ R3.3 Sync — Release v0.2.0

Крупное обновление утилиты безопасной синхронизации TOTP-профилей между KeePassXC и аппаратными USB-токенами Token2 PIN+ R3.3: автономный стек без внешних CLI-зависимостей, интерактивный TUI с мастером первого запуска, нативный выбор файлов ОС и портативная standalone-сборка.

## Ключевые возможности v0.2.0

### 1. Автономный стек без внешних CLI (Zero-External-CLI)
- **Встроенный драйвер Token2 USB-HID**: Прямое взаимодействие с аппаратными ключами Token2 (USB-HID feature reports, 65 байт, сигнатура `0x21`) через библиотеку `hidapi` без необходимости устанавливать или вызывать внешний `token2-otp-cli`.
- **Криптографический протокол NIST P-256 ECDH + AES-256-CBC**: Встроенная реализация спецификации Token2 для защищенного рукопожатия и безопасной передачи seed в память токена (с векторизацией IV-1).
- **Прямое чтение баз KeePass (KDBX) в RAM**: Дешифрование баз KDBX 3.1, 4.0 и 4.1 напрямую в оперативной памяти с помощью `pykeepass` (поддержка шифров AES, ChaCha20, Twofish и алгоритмов KDF Argon2id/AES-KDF) без необходимости вызова `keepassxc-cli`.
- **Мульти-схемный парсинг TOTP**: Поддержка как стандартных `otpauth://` URI, так и кастомных полей KeeOtp / TrayTOTP (`TimeOtp-*`).
- **Гибридный роутинг**: Автоматический fallback на `keepassxc-cli` при использовании аппаратного YubiKey challenge-response (слоты 1/2) и на внешний `token2-otp-cli`, если в ОС недоступен `hidapi`.

### 2. Интерактивный TUI и Мастер первого запуска (Onboarding Wizard)
- **Мастер первичной настройки**: При отсутствии файла конфигурации или первом запуске программа пошагово помогает настроить путь к базе KDBX, ключевой файл и параметры синхронизации.
- **Главное интерактивное меню**:
  - `[1] Запуск синхронизации` (с выбором режимов: `Add Only`, `Add & Update`, `Full Sync` с подтверждением удаления)
  - `[2] Тестовый прогон (Dry Run)` — безопасная сверка без записи на физическое устройство
  - `[3] Настройки в TUI` — встроенный редактор путей к базе, keyfile, слотов YubiKey и исключаемых групп
  - `[4] Выход`
- **Нативный выбор файлов ОС**: Кнопка «Обзор» открывает нативный диалог операционной системы (PowerShell OpenFileDialog в Windows, zenity/kdialog/tkinter в Linux/macOS) с автоматическим переходом на текстовый ввод в SSH/headless окружениях.

### 3. Автономная сборка и портативная дистрибуция (Standalone Executables)
- **Сборка PyInstaller**: Автономный исполняемый файл Linux (`dist/t2-kpxc-sync`) и Windows (`dist/t2-kpxc-sync.exe`) с полным комплектом бинарных библиотек (`hidapi`, `cryptography`, `lxml`).
- **Умные лаунчеры в 1 клик**: `Sync-Token2.sh` (Linux), `Sync-Token2.bat` (Windows) и `Sync-Token2.command` (macOS), автоматически находящие скомпилированный бинарник или использующие локальное Python-окружение.
- **Детерминированный упаковщик дистрибутивов**: Скрипт `scripts/package_dist.py` формирует портативные архивы `.tar.gz` и `.zip` со всеми необходимыми файлами, документацией и интерактивной картой архитектуры `docs/architecture.html`.
- **GitHub Actions Release CI**: Автоматическая сборка для Linux и Windows при публикации тегов `v*`.

### 4. Всестороннее тестирование и архитектура
- **4-уровневая пирамида E2E и Chaos тестов**: 394 автоматических теста (Tier 1 Features, Tier 2 Boundaries, Tier 3 Combinations, Tier 4 Scenarios, Chaos Battery, Zero-Disk Verification).
- **Синхронизация Archify**: Интерактивная архитектурная карта системы `docs/architecture.html` актуализирована под архитектуру v0.2.0 (0 ошибок, 0 предупреждений).
- **Zero-Disk-Footprint & Memory Scrubbing**: Полная гарантия отсутствия записи промежуточных дампов на диск и зануление буферов секретов в памяти (`bytearray`).

1. `t2-kpxc-sync-v0.2.0-linux-x64.tar.gz` — Портативный архив для 64-битного Linux со скомпилированным бинарником, лаунчером `Sync-Token2.sh`, документацией и архитектурной картой.
2. `t2-kpxc-sync-v0.2.0-windows-x64.zip` — Портативный архив для 64-битного Windows со скомпилированным `.exe`, батником `Sync-Token2.bat` и документацией (формируется через GitHub Actions Release Workflow).
3. `SHA256SUMS.txt` — Контрольные суммы файлов дистрибутива.
