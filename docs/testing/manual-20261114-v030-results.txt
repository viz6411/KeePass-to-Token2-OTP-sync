FEATURE SUMMARY: TOTP ENTRY FORMAT SELECTION (STANDARD VS TOUCH REQUIRED)
--------------------------------------------------------------------------------
1. Interactive prompt during sync workflow:
   - Called on the final step after selecting sync mode (Add Only, Add & Update, Full Sync)
     and immediately before executing write operations (`apply_sync`).
   - Prompt choices:
     [1] Standard format (default) — OTP generated on demand without button press
     [2] Require a button press to show the code (Touch Required)
2. Configuration support:
   - `config.toml` & `config.example.toml`: `[token2] button_required = true/false`
   - Default value `False` (Standard format).
3. TUI Settings Editor:
   - Added option `[6] Изменить формат TOTP по умолчанию`.
   - Settings summary panel displays current configured format.
4. CLI batch mode:
   - Added flag `--button-required` for non-interactive synchronization.
5. Low-level USB-HID protocol and adapter:
   - `Token2Adapter.write_entry` and `Token2DirectClient.write_entry` receive `btn_flag`
     (0x00 for standard, 0x01 for touch required).
   - In `CMD_WRITE_SEED` decrypted payload, byte 5 (`btn_flag`) is set to 0x00 or 0x01.
   - `Token2CLIAdapter` appends `--button-required` when `btn_flag != 0`.
   - `Token2Profile` tracks `btn_flag` on listed token profiles.
