# Project: KeePass to Token2 OTP Sync

## 1. Назначение проекта
Кроссплатформенная защищенная консольная утилита для синхронизации TOTP-профилей из зашифрованной базы KeePassXC (`.kdbx`) на аппаратные токены безопасности **Token2 PIN+ R3.3** (емкостью до 300 профилей).

## 2. Ключевые архитектурные инварианты
1. **Zero-Disk-Footprint & Read-Only KDBX**: База данных KeePassXC открывается **строго в режиме Read-Only**. Никаких промежуточных файлов, дампов или слепков на диск не записывается. Весь обмен данными — потоковый pipe в RAM (`io.BytesIO`).
2. **Сравнение актуальности без изменения базы**: Для детекции ротации секрета утилита сравнивает генерируемый в памяти текущий TOTP-код с кодом, возвращаемым токеном на момент $T$.
3. **Безопасность памяти**: Все пароли и секреты хранятся в `bytearray` и гарантированно зануляются в блоках `finally`.
4. **Защита от блокировки токена**: При ошибке ввода PIN операция немедленно прекращается без повторных попыток.

## 3. Технологический стек
- Python 3.11+
- `keepassxc-cli` (основной CLI движок KeePassXC)
- `token2-otp-cli` (официальный CLI / протокольный адаптер Token2)
- `rich` (консольный UI, таблицы расхождений)
- `pytest` (модульное и сквозное тестирование)
- `archify` (интерактивная карта архитектуры)
- `codegraph` (индексация графа зависимостей и символов)
